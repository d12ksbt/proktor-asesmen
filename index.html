⚠️ Perhatian: File Dibuka Secara Lokal (file://)

Login Google Firebase tidak dapat berjalan di protokol file:///. Upload file ini sebagai index.html ke GitHub Pages, lalu tambahkan domain GitHub Pages Anda di Firebase Console → Authentication → Settings → Authorized domains.
