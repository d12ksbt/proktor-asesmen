⚠️ Perhatian: File Dibuka Secara Lokal (file://)

Login Google Firebase tidak dapat berjalan di protokol file:/// karena kebijakan keamanan OAuth Google. Agar bisa login, upload file ini sebagai index.html ke GitHub Pages (atau jalankan via Local Web Server seperti VSCode Live Server), lalu tambahkan domain GitHub Pages Anda (misal: username.github.io) di Firebase Console → Authentication → Settings → Authorized domains.

Akses Khusus Proktor / Admin

Silakan masuk menggunakan akun Google Admin Proktor untuk mengelola jadwal ujian berbasis tanggal, mengedit/mereset status peserta, dan memantau pelanggaran secara realtime.

Panduan Agar Login Google Berfungsi di GitHub Pages:

  1. Ubah nama file ini menjadi index.html dan upload ke repository GitHub Anda, lalu aktifkan GitHub Pages.
  2. Buka Firebase Console → Authentication → Settings → Authorized domains.
  3. Klik Add domain dan masukkan domain GitHub Pages Anda (contoh: nama-akun.github.io).
